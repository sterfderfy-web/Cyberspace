## Особенность окружения

На ноутбуке Kaspersky внедряет запрос к `me.kis.v2.scr.kaspersky-labs.com` в HTTP-страницы. Тест блокирует **все** внешние запросы, включая этот скрипт, и отдельно учитывает внедрение окружения. Необязательных внешних запросов приложения не обнаружено; исходный HTML, возвращаемый Fastify до внешнего вмешательства, не содержит внешних ссылок или скрипта Kaspersky. Работа приложения при блокировке проверена, антивирус и его настройки не менялись.

## Воспроизведение и артефакты

После `npm ci` и `npm run build`:

```powershell
npm run check
npm test
$env:CYBERSPACE_TEST_HOST = '192.168.1.104' # замените на текущий Wi-Fi IP
npm run test:browser
npm audit
```

Исходники: `tests/acceptance/api.test.ts`, `process.test.ts`, `browser.spec.ts`, общая изолированная fixture. Локальный HTML-отчёт: `playwright-report/index.html`. Снимки трёх размеров: `.local/screenshots`. Отчёты, трассы, секреты и базы не публикуются в git. Для ручного прогона на устройствах используйте [RUNBOOK.md](RUNBOOK.md).

Открытых FAIL в финальном локальном прогоне нет. Полная физическая приёмка A01/A02/A12 и проверка телефона/планшета остаются за владельцем. 3D, федерация, аппаратное управление и настоящая LLM находятся вне согласованного этапа.
