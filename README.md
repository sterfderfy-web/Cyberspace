# Cyberspace

Открытая распределённая среда взаимодействия людей, программных агентов, объектов и инструментов.

- [Манифест Cyberspace v0.1](MANIFESTO.md) — принципы и архитектурный фундамент проекта.
- [Инструкции для агентов](AGENTS.md) — правила работы с репозиторием.

Проект находится на начальном этапе: реализации пока нет, технологический стек и границы первого прототипа ещё не утверждены.
