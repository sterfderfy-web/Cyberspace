# Cyberspace

Открытая распределённая среда взаимодействия людей, программных агентов, объектов и инструментов.

- [Манифест Cyberspace v0.1](MANIFESTO.md) — принципы и архитектурный фундамент проекта.
- [Инструкции для агентов](AGENTS.md) — правила работы с репозиторием.

Первый локальный прототип: два человека и отдельный программный агент работают с текстовыми заметками пространства «Мастерская». Сервер проверяет права, сохраняет состояние в SQLite и синхронизирует подтверждённые изменения. Агент детерминированный, **без LLM**.

## Запуск на подготовленном ноутбуке

```powershell
cd C:\cyberspace
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\cyberspace.ps1 start
```

Откройте `http://localhost:3210`. Учётные данные находятся в локальном `.local/credentials.json`; для другой машины выполните первоначальную установку из [инструкции](docs/RUNBOOK.md). По LAN открывается `http://<IPv4-ноутбука>:3210`; брандмауэр разрешается отдельным правилом для доверенной частной сети.

## Стек и команды

Node.js 24.22.2 LTS, TypeScript 7.0.2, Fastify 5.12.7, React 19.3.1, Vite 8.3.5, встроенный `node:sqlite`. Прямые версии зафиксированы в `package.json`, транзитивные — в `package-lock.json`, пакеты организованы через npm workspaces. Работа после сборки не требует CDN, внешних шрифтов, сервиса авторизации или облачной модели.

При Node.js в PATH:

```text
npm ci
npm run check
npm run build
npm run setup
npm start
```

`setup` выполняется один раз и не перезаписывает существующие данные. Проверки после сборки: `npm test` и `npm run test:browser`. Подробности разработки, настройки адреса, портов и запуска агента — в инструкции.

## Границы прототипа

Один сервер записи на SQLite, пространство с текстовыми заметками, встроенный доверенный модуль notes. Права выдаются на всё пространство. Посимвольного совместного редактирования, offline-очереди, федерации, 3D, оборудования и настоящей модели ИИ пока нет. Несохранённые черновики живут в памяти вкладки. HTTP разрешён только для демонстрации в доверенной LAN с тестовыми секретами; публичная эксплуатация в этот этап не входит.

Исходный манифест сохранён. Лицензия остаётся решением владельца проекта; эта реализация её не выбирает.
